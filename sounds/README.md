# Arcade sounds

The site works if optional files are missing.

Main arcade filenames expected by `js/config.js`:

- `button.mp3`
- `tick.mp3`
- `spin.mp3` — supplied; Wheel Mode is timed to its 8.307-second length
- `case-click.mp3`
- `reel.mp3`
- `winner.mp3`
- `accept.mp3`
- `reroll.mp3`

Player-triggered sounds belong in `sounds/soundboard/` and are configured in `js/soundboard.js`.
